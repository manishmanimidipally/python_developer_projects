# 💰 Smart Finance Web App

## 🚀 Overview

Smart Finance Web App is a full-stack web application built using Flask that allows users to manage their income and expenses efficiently. The application supports complete CRUD operations and provides a clean dashboard interface for tracking financial data.

---

## ✨ Features

* ➕ Add new transactions (Income & Expense)
* 📋 View all transactions in a dashboard
* ✏️ Edit existing transactions
* 🗑️ Delete transactions
* 🔢 Manual ID input with validation
* 💾 SQLite database integration
* 🎨 Styled user interface using HTML & CSS

---

## 🛠️ Tech Stack

* **Backend:** Python (Flask)
* **Database:** SQLite
* **Frontend:** HTML, CSS
* **Tools:** Git, VS Code

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/manishmanimidipally/python_developer_projects.git
cd python_developer_projects/Smart\ Finance\ Web\ App
```

### 2️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run the application

```
python app.py
```

### 4️⃣ Open in browser

```
http://127.0.0.1:5000/
```
